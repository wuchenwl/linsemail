# Linsemail v0.3.0 — 统一 API、持续取件与邮件匹配

Linsemail 将临时邮箱创建、收件、正文阅读和邮件匹配整合为一个本地工作台。网页与脚本共用一套 API，适合开发、QA 和邮件流程验证。

## 本版本提供

- 97 个外部来源适配器，覆盖创建邮箱、列信与正文读取；来源目录共 127 项。
- 统一 API：异步邮箱操作、幂等请求、按箱授权、持久化等待任务和实时事件。
- 自动取件与邮件匹配：按发件域名、主题、正文筛选来信，命中后读取对应邮件。
- 可核对的验证码与链接提取结果，保留来源位置与歧义状态。
- 三栏收件台、本机 SMTP 测试箱，以及中文默认文档与英文指南。

97 是协议适配实现数。61 个适配器无需平台密钥，34 个需要自己的平台凭证，2 个需要自部署配置。上游在线状态与实际投递能力需要按使用场景核验。

## English

Linsemail unifies temporary mailbox creation, continuous retrieval, message inspection and persistent matching tasks behind one local API and workspace.

This release includes 97 implemented provider adapters across a catalog of 127 external entries, asynchronous operations, idempotency, mailbox-scoped access tokens, live events, inspectable extraction results and local SMTP capture. Adapter coverage is separate from live availability and delivery; 61 adapters require no platform key, 34 need provider credentials and two need self-hosted configuration.

The attached archives contain source, tests, documentation and synthetic screenshots. Runtime data and credentials are excluded. The automatic launcher targets Windows; Linux/macOS use the documented manual setup. CI runs on Ubuntu.
