# Linsemail v0.3.1 — 依赖安全更新

本版本更新存在公开漏洞的依赖，并保持统一邮箱 API、持久化取件与现有工作区数据格式。

| 依赖 | 原版本 | 更新版本 |
| --- | --- | --- |
| cryptography | 46.0.3 | 50.0.2 |
| Starlette | 0.48.0 | 1.9.0 |
| FastAPI | 0.119.1 | 0.148.0 |
| pytest | 8.4.2 | 9.1.1 |
| Vite | 7.1.10 | 7.3.7 |
| @vitejs/plugin-react | 5.0.4 | 5.2.0 |

同时更新 Python 和 npm 锁文件，并在 CI 中加入依赖安全扫描。具体告警状态以 GitHub Security 页的最新扫描结果为准。

## 验证

- 后端与集成测试：402 项通过，另有 18 项子测试通过。
- 中英文文案与语言偏好检查：259 项通过；生产前端构建通过。
- `pip-audit` 检查 34 项锁定 Python 依赖、`npm audit` 检查前端和 PostgreSQL 工具依赖：均未发现已知漏洞。
- 旧版 cryptography 生成的 Fernet 测试数据可由新版本解密。扫描结果对应本次发布时的漏洞数据库。

## 升级

先停止服务并备份原工作区的 `.runtime/`，保留数据库、密钥和本机配置。更新源码后，Windows 用户重新运行 `scripts/start-console.ps1`，安装本版本锁定依赖并重建前端。Linux/macOS 用户按[手动部署说明](https://github.com/wuchenwl/linsemail/blob/main/docs/architecture.zh-CN.md#手动部署)更新依赖、重建前端并重启服务。

不要用新生成的密钥替换原 `.runtime/` 中的加密密钥，否则无法读取原有来源会话。本版本无数据库 schema 变更。

下载附件中的源码 ZIP 或 tar.gz，校验值见 `SHA256SUMS`。旧版 v0.3.0 保留用于版本追溯，建议升级到本版本。

## English

This patch upgrades vulnerable Python and frontend dependencies, refreshes lockfiles and adds dependency auditing to CI. Mailbox API contracts and persisted data formats are preserved; there are no database schema changes.

Validation: 402 backend/integration tests and 18 subtests passed; 259 translation/preference checks and the production frontend build passed. `pip-audit` and both npm audits found no known vulnerabilities at release time. A synthetic Fernet token generated with the old cryptography version decrypted successfully with the new version.

Stop services and back up the existing `.runtime/` before updating. Reinstall the locked dependencies, rebuild the frontend and restart. Keep the original database configuration and encryption key so existing provider sessions remain readable. Source archives and SHA256 checksums are attached.
