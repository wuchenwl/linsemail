## English release introduction

Linsemail brings temporary receiving addresses, message inspection and mail-driven automation into one local workspace. Its monochrome interface supports English and Simplified Chinese, while the unified API exposes asynchronous mailbox operations, scoped access tokens, persistent wait tasks and live events. The catalog contains 127 external providers with 97 implemented adapters; credential requirements and recent live checks are reported separately from implementation coverage.

This release includes bilingual guides, synthetic page screenshots, MIT licensing, contributor policies and clean source archives. It does not bundle runtime data, private inboxes, dependency binaries or research captures.
